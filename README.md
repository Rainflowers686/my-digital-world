Rain Lab is a personal website for projects, notes, learning and experiments.

The site uses Astro 6, TypeScript, Tailwind CSS v4, React 19 and MDX. Its source and content live in this repository; the site address is [rain-lab.com](https://rain-lab.com).

## Project status

The live site is rain-lab.com; this repository contains its Astro source and content.

## Work locally

~~~sh
npm ci
npm run dev
~~~

Use the package scripts in package.json for a production build or preview. Keep private notes, credentials and machine-specific settings out of public content.

## Repository layout

- src/ — site source
- public/ — static assets
- docs/ — project notes
