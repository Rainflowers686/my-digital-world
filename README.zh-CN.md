# Rain Lab

*记录项目、笔记、学习和实验的个人网站。*


[English](README.md) | [简体中文](README.zh-CN.md)

**导航：**[状态](#项目状态) · [本地运行](#本地运行) · [仓库结构](#仓库结构)


Rain Lab 是个人网站，用来记录项目、笔记、学习和实验。

网站使用 Astro 6、TypeScript、Tailwind CSS v4、React 19 和 MDX 构建。源码与内容位于本仓库；网站地址为 [rain-lab.com](https://rain-lab.com)。

## 项目状态

网站地址为 rain-lab.com；本仓库保存 Astro 源码与内容。

## 本地运行

~~~sh
npm ci
npm run dev
~~~

生产构建或预览请使用 package.json 中的脚本。不要把私人笔记、凭据或机器专属设置放进公开内容。

## 仓库结构

- src/：网站源码
- public/：静态资源
- docs/：项目说明
