## 5. 建议后续版本

### V1.5 可以做
- 更新 README 和 Case Study 的版本路线表
- 补充 `cs-learning-notes` 项目 MDX 的正文内容（当前偏短）
- 补充 `algorithm-visualizer` 项目 MDX 的实现进度（开始编码后更新 status）
- 考虑加入 `@astrojs/sitemap` 自动生成 sitemap
- 在 Footer 中替换真实的 GitHub/Twitter/Email 链接

### 暂时不建议
- 不要做评论系统
- 不要做搜索功能
- 不要做国际化多语言
- 不要迁移到 SSR 模式
- 不要引入 CMS 或数据库
- 不要大规模重组目录结构
- 不要改 `package.json` 的 `name` 字段（风险低但会影响 npm 行为）
