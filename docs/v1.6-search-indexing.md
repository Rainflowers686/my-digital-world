## Google Search Console 手动步骤

### 1. 添加资源

1. 打开 [Google Search Console](https://search.google.com/search-console)
2. 点击「添加资源」
3. 选择 **Domain** 类型（推荐，覆盖 `rain-lab.com` 和 `www.rain-lab.com`）
4. 输入：`rain-lab.com`
5. 点击「继续」

### 2. 域名验证

Google 会提供一条 TXT 记录用于 DNS 验证，格式类似：
```
google-site-verification=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

1. 复制这条 TXT 记录
2. 打开 Cloudflare Dashboard → 选择 `rain-lab.com` → DNS → Records
3. 添加记录：
   - Type: `TXT`
   - Name: `@`（或留空，取决于 Cloudflare 界面提示）
   - Value: 粘贴 Google 提供的完整 TXT 值
   - TTL: Auto
4. 保存后等待 1-2 分钟
5. 回到 Google Search Console 点击「验证」

### 3. 提交 Sitemap

验证通过后：

1. 左侧菜单 → Sitemaps
2. 输入：`https://rain-lab.com/sitemap-index.xml`
3. 点击「提交」
4. 状态应显示为「成功」或「已处理」

### 4. 等待索引

- Google 会自动开始抓取，通常 1-7 天内新页面会出现在搜索结果中
- 可以在 Search Console 中查看「覆盖率」报告追踪进度

## Bing Webmaster Tools 手动步骤

### 方法一：从 Google Search Console 导入（推荐）

1. 打开 [Bing Webmaster Tools](https://www.bing.com/webmasters)
2. 登录后点击「添加站点」
3. 输入 `https://rain-lab.com`
4. 选择「从 Google Search Console 导入」（需要先用同一 Google 账号登录 GSC）
5. 确认导入后，Bing 会自动获取已验证状态和 sitemap

### 方法二：手动添加

1. 在 Bing Webmaster Tools 中添加 `rain-lab.com`
2. 选择 DNS TXT 验证方式
3. 在 Cloudflare DNS 添加 Bing 提供的 TXT 验证记录
4. 验证通过后，手动提交 sitemap：
   ```
   https://rain-lab.com/sitemap-index.xml
   ```

## 后续可选

| 优化项 | 说明 |
|--------|------|
| Google site verification meta | 在 Layout.astro 中添加 `<meta name="google-site-verification">` 替代 DNS 验证（如果 DNS 方式不便） |
| JSON-LD WebSite | 在 Layout.astro 中添加 `@type: WebSite` 结构化数据，帮助搜索引擎理解站点 |
| JSON-LD Person | 添加 `@type: Person` 结构化数据，关联作者信息 |
| Plausible Analytics | 轻量隐私友好的访问统计，可在 Cloudflare Pages 中通过 `<script>` 引入 |
| Cloudflare Web Analytics | Cloudflare 自带的分析工具，无需额外脚本即可启用 |
