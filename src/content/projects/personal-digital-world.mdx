## 概述

这是我的个人数字空间——一个集项目展示、学习记录与技术写作于一体的网站。从零开始构建，不使用模板，每一行代码都是对现代 Web 开发的理解与实践。

## 技术选型

- **Astro 6** — 静态站点生成，岛屿架构，零 JS 默认输出
- **Tailwind CSS v4** — CSS 优先的主题定制，设计 token 体系
- **MDX** — 内容集合管理，Markdown 中嵌入组件
- **React 19** — 仅用于需要交互的组件（导航菜单、背景选择器）

## 设计理念

采用 Claude 风格的暖色极简设计——米黄纸感背景、Georgia 衬线标题、等宽技术标签、克制留白。不追求视觉刺激，只追求安静舒适的内容阅读体验。

## 迭代过程

项目经历了多次视觉方向调整，从最初的黑紫科技风转向暖色极简风格。这个过程让我理解了设计系统的重要性——一旦建立了统一的设计 token，后续扩展页面时无需反复纠结样式。
